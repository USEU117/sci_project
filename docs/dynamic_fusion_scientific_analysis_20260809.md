# 动态融合 V1 科学分析报告

日期：2026-08-09  
状态：已完成，V1 保持冻结，不根据最终验证结果继续调参  
计算资源：CPU 分析，无 GPU 训练

## 1. 本次分析回答什么问题

本次工作不是再寻找一组更好的参数，而是回答三个问题：

1. 为什么动态融合没有像预期那样超过强视觉分支？
2. 动态融合是否仍然产生了可解释的局部收益？
3. 论文中哪些结论可以写，哪些结论不能写？

分析覆盖 17 个已经冻结的最终运行：MVTec 9 组、VisA 8 组，共 231 个“类别—运行”组合。视觉分支为 AnomalyDINO，文本分支为 AnomalyCLIP。所有运行继续满足 `test_predictions_used=false` 和 `test_labels_used=false`。输入来源清单共有 693 行，覆盖 285 个唯一视觉缓存、文本缓存和样本编号 sidecar；每个文件均记录路径、大小、修改时间和 SHA256。

## 2. 先说结论

动态融合不符合预期的主要原因不是 AnomalyDINO 太弱，而是进入路由器之前的分数校准发生了严重饱和。

当前流程先用少量正常参考图估计中位数和 MAD，再用 sigmoid 把两条分支的分数变成 0—1 范围。这个变换在数学上本来保持大小顺序，但实际实现还包含缩放、裁剪和有限精度。当参考分布尺度过小、测试图分数远离参考范围时，大量不同的测试分数都会被压到几乎相同的 1，最终形成大量并列值。

MVTec 中，视觉校准分数落在 `>=0.999` 区域的平均比例为 99.99%；VisA 为 91.54%。MVTec 原始 AnomalyDINO 的平均类别级 Image AUROC 为 95.71%/96.86%/97.46%，校准后分别降到 51.53%/54.46%/56.74%。这说明强视觉分支的排序信息在进入路由前已经大幅丢失。

## 3. 为什么路由器没有自动发现问题

### 3.1 当前“不确定性”把饱和错误当作高置信

路由器用二元熵衡量分支置信度。分数接近 0 或接近 1 时，熵都很低，也就是被当作“很有把握”。因此，一个由校准饱和产生的 0.999999，会被路由器误认为是非常可靠的异常判断，而不是“超出校准范围、不能相信”。

这形成了连续问题：

`参考尺度过小 -> sigmoid 饱和 -> 大量分数并列 -> 熵很低 -> 路由器误判为高置信 -> 权重不能纠错`

### 3.2 权重和真正的分支优势相关性不够强

如果路由器科学有效，某一类别中 AnomalyDINO 明显强于 AnomalyCLIP 时，视觉平均权重也应明显更高。实际类别级 Spearman 相关性较弱：MVTec 按 shot 平均约为 0.10、0.16、0.20；VisA 约为 0.36、0.37、0.31。

这意味着当前权重反映的主要是“校准后分数形状”，不是“哪条分支在这个样本上更可能正确”。

### 3.3 没有真正的文本主导

MVTec 三个 shot、三个 seed 共 5,175 个路由判断中，文本主导为 0；VisA 只有极少量文本主导。大量样本被标记为加权融合或视觉主导。

因此，离散标签“视觉主导/文本主导/加权融合”本身并没有证明路由器学会了分支选择。真正决定结果的是连续权重，而连续权重又受饱和校准影响。

### 3.4 样本相关权重会改变全局排序

Image AUROC 看的是所有正常图和异常图的相对排名。如果每张图使用不同权重，即使每个分支内部排序不错，混合后也可能把某些正常图抬高、把某些异常图压低，破坏全局排名。

MVTec 动态分数与原始视觉分数的类别级平均 Spearman 相关性只有约 0.54，说明融合后的排序与强视觉分支已经明显不同。

## 4. 最终结果和差距

### 4.1 MVTec 三个 seed 的平均结果

| Shot | 原始 AnomalyDINO Image AUROC | Dynamic Image AUROC | 差值 | Dynamic Pixel AUROC | Dynamic AUPRO |
|---|---:|---:|---:|---:|---:|
| 1 | 95.71% | 79.43% | -16.29 个百分点 | 91.06% | 82.33% |
| 2 | 96.86% | 86.37% | -10.49 个百分点 | 93.79% | 90.58% |
| 4 | 97.46% | 89.52% | -7.94 个百分点 | 94.18% | 91.81% |

shot 增加后差距缩小，但三个 shot 均未超过原始视觉分支。不能把这种趋势写成“动态融合优于 AnomalyDINO”。

### 4.2 类别级结果

MVTec 平均下降最明显的类别是 carpet、cable、grid、zipper 和 bottle。例如 carpet 的原始视觉 AUROC 为 100%，动态融合约为 61.31%；cable 从约 92.36% 降到 54.02%。这些类别的视觉校准分数几乎全部饱和。

少数类别保持或略有改善：capsule 平均约增加 1.42 个百分点，wood 约增加 0.54 个百分点，leather 基本持平。它们证明分支互补并非完全不存在，但不足以支持总体优越性。

## 5. 图像任务与像素任务为什么表现不同

图像级任务只需要给整张图排序；像素级任务需要指出异常位置。两者依赖的信息不同，所以共用一个路由温度并不合适。

VisA seed 0 消融表显示：

- 图像温度从 0.20 提高到 0.50，能减少图像权重过度贴近上限，改善 Image AUROC。
- 像素温度保持 0.20，能保留更强的局部选择性和 AUPRO。
- K=2 时，双温度相对最佳固定权重的 Image AUROC 增加 0.20 个百分点，AUPRO 增加 4.14 个百分点。
- K=4 时，Image AUROC 增加 0.04 个百分点，AUPRO 增加 8.82 个百分点。
- K=1 时，Image AUROC 比最佳固定权重低 0.07 个百分点，但 AUPRO 高 2.78 个百分点。

所以“双温度”解决的是图像目标和定位目标之间的冲突，但它没有解决更上游的校准饱和问题。

## 6. 成功和失败案例怎样理解

成功案例中，文本热图能补充视觉分支没有覆盖的细长结构，像素权重在结构边缘产生选择，融合后异常区域对比度提高。当前自动选出的前三个成功案例均来自 zipper。

失败案例包括 zipper-fabric_interior、tile-rough 和 metal_nut-bent。共同现象是：原始视觉图已准确集中在真值区域，但融合热图把高响应扩散到纹理、主体轮廓或大面积背景，导致定位对比度下降。

这些案例只能用于解释机制，不能用于重新选择 V1 参数，因为它们来自已经查看过的最终验证结果。

## 7. 论文中可以写什么

可以写：

- 提出并实现了图像级、像素级分开的不确定性路由接口。
- 完成了严格的缓存对齐、正常参考校准和禁止测试真值的协议。
- 双温度消融在 VisA seed 0 上显示像素定位和图像排序需要不同路由强度。
- 最终验证揭示了参考校准饱和和熵置信度的局限，并给出类别级、权重级和可视化证据。
- V1 在部分样本和部分定位指标上存在互补收益，但没有全面超过最强单分支。

不能写：

- “动态融合全面优于 AnomalyDINO”。
- “文本分支能够稳定接管视觉分支失败样本”。
- “最终验证证明路由器可以准确识别更可靠分支”。
- 把看过最终结果后提出的 V2 改进继续在同一最终集上调参，再当作独立验证。

## 8. 后续还需要什么

V1 的科学分析、消融整理和可视化已经完成，不再需要 GPU。论文初稿可以直接使用本报告和工作簿中的材料。

如果以后开发 V2，建议按优先级研究：

1. 增加校准饱和保护：检查超出参考分布范围的比例，不把饱和值直接当作高置信。
2. 使用保持排序的校准或分位数/经验分布映射，避免大量并列值。
3. 给 MAD/尺度设置合理下限，或使用更有代表性的源域正常参考分布。
4. 不确定性改为“离参考分布多远、两分支是否冲突、增强后是否稳定”，而不只依赖校准概率的熵。
5. 图像级和像素级分别设计路由目标。
6. 为 V2 重新建立开发集和最终验证集，避免使用本次已经查看的最终结果调参。

以上 V2 内容是后续研究建议，不属于今天完成的 V1 结果，也不应立即启动 GPU。
