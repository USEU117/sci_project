## 3. 主图完整内容

### 3.1 正常支持集建库

1. 输入类别 c 的正常支持集 R_c，共 K 张已确认正常的图像，K ∈ {1, 2, 4}。
2. 对每张支持图像分别执行冻结的 DINOv2 与 CLIP/DPAM 视觉特征提取，每个分支的局部描述子为 768 维。
3. 将 CLIP 的特征网格双线性对齐到 DINO 网格。
4. 对每个位置的两个分支分别做 ℓ₂ 归一化。
5. 对两个分支固定乘以 0.5，沿通道维拼接，再对拼接向量整体做 ℓ₂ 归一化。
6. 收集所有支持图像的 1536 维融合 patch 描述子，形成该类别的正常记忆库 M_c。
7. 建库结束后，查询阶段读取这份固定记忆库。

### 3.2 查询与输出

1. 查询图像 x 使用与支持图完全相同的冻结编码器及融合过程。
2. 每个查询 patch 的融合向量在固定正常记忆库中执行精确 1-NN 检索。
3. 使用最近邻平方欧氏距离的二分之一作为原始 patch 异常分数。
4. 将 patch 分数按 DINO 网格恢复空间排列，双线性放大到 448 × 448。
5. 用 σ = 4 的高斯滤波得到最终异常图 S_448(x)。
6. 对平滑后的异常图取空间最大值，得到图像级异常分数 s_img(x)。

主图的箭头表达数据流：查询图只产生待匹配的描述子，没有向正常记忆库写入的箭头。DINO-only 是独立实验对照，详细结构在 Fig. S1 中解释。

## 4. 分图 1：双编码器视觉表示

### DINOv2 分支

- 冻结 DINOv2 ViT-B/14。
- 输入图像按固定预处理将短边调整为 448，并裁剪到各空间尺寸可以被 patch size 14 整除。
- 输出 F_D，尺寸 h_D × w_D × 768。
- 网格较短的一维为 32。对于非方形输入，另一维由预处理后的尺寸决定，因此不把所有输入统一写死成 32 × 32。

### CLIP / DPAM 分支

- 冻结 CLIP ViT-L/14@336 视觉编码器，使用 AnomalyCLIP 的 DPAM 配置。
- 实际输入尺寸为 518 × 518，输出 patch 网格为 37 × 37。
- DPAM_layer = 20。
- 实现请求层 6、12、18、24 的输出，但最后只保留返回列表中的最后一项，即第 24 层局部特征，并去掉 CLS token。
- 输出 F_C，尺寸 37 × 37 × 768。
- “@336”是模型型号的一部分；本实现输入 518，不应因为型号中出现 336 就把图中的实际输入改成 336。

本图不表示四层特征拼接，也不包含文本编码器、提示词或图文相似度评分。网格小方块只是结构示意，实际尺寸由图中标注给出。

## 5. 分图 2：空间校准和固定融合

图的上半部分解释空间，下半部分解释每个 patch 的通道运算。

### 空间校准

F_C→D = Resize_bilinear(F_C, target = (h_D, w_D))，其中 align_corners = False。

只有 CLIP 特征网格执行这一重采样，DINO 网格提供目标尺寸。该步骤对齐空间采样网格，不是学习几何变换或图像配准网络。

### 幅值校准与通道融合

对每个位置 p：

```text
g_D,p = f_D,p / max(||f_D,p||₂, ε)
g_C,p = f_C→D,p / max(||f_C→D,p||₂, ε)
f_A,p = norm([0.5 g_D,p ; 0.5 g_C,p])
norm(v) = v / max(||v||₂, ε)
```

每支 768 维，拼接后 1536 维。图中用蓝、黄两个半段保留通道来源，紫色模块表示校准与融合运算。向量色块不表示实际特征数值。

这一版本使用固定系数。它不是可训练的动态门控，也不是把两张已经计算完成的异常图做 0.5 / 0.5 平均。由于先拼接再执行共同的最近邻检索，其数学含义应通过融合描述子的共同距离来解释。

冻结配置没有 PCA 或 whitening。早期评估脚本提供过这些可选参数，但当前图件依据 pca_dim = 0、whiten = false 的实际冻结配置。

## 6. 分图 3：正常记忆与异常评分

### 记忆内容

对类别 c，将 K 张正常支持图像的融合 patch 描述子取并集，形成 M_c。若各图保留相同 P = h_D w_D 个 patch，则记忆矩阵包含 KP 个 1536 维向量。

使用 FAISS IndexFlatL2 精确存储及检索。图中没有额外画出训练器、聚类中心、压缩模块或 coreset，因为这些不属于当前冻结流程。

### 匹配规则

```text
a_p(x) = ½ min_{m ∈ M_c} ||f_A,p(x) − m||₂²
```

“最近”指特征空间中的距离。每个查询 patch 可以匹配所有支持图像、所有已存储位置的描述子，不是只能匹配同一空间坐标。

融合描述子经过单位归一化，所以平方欧氏距离的二分之一具有余弦距离解释。不能遗漏“平方”，也不能把二分之一误写为系数 12。

### 空间恢复与输出

```text
patch scores on the DINO grid
bilinear resize to 448 × 448
Gaussian smoothing with σ = 4
S_448(x)
s_img(x) = max_u S_448,u(x)
```

最大值取自平滑后的最终异常图。图中的异常图展示既有结果，不是新一轮实验或新性能结论。

## 9. 可直接用于初稿的英文图注

### Fig. 1. Overall workflow of DCFnet

Normal support images construct a category-specific memory. Query images use the same frozen visual encoders and calibrated fusion operator, and their descriptors are compared with the fixed memory. Exact nearest-neighbor distances are upsampled and Gaussian-smoothed to obtain the anomaly map. The image score is the spatial maximum of this map. The displayed input and anomaly map are an illustrative MPDD example.

### Fig. 2. Frozen visual feature extraction

DINOv2 produces 768-dimensional patch descriptors on its native grid after aspect-ratio-preserving resizing and patch-compatible cropping. The CLIP visual encoder uses the fixed DPAM configuration and retains layer-24 patch descriptors on a 37 × 37 grid. Both branches process each support or query image independently. Only visual patch descriptors enter fusion. Drawn grid cells are schematic; the labels specify the actual tensor dimensions.

### Fig. 3. Spatial and magnitude calibration before fixed fusion

The CLIP grid is bilinearly resized to the DINO grid. At each aligned location, the two 768-dimensional branch descriptors are independently normalized, scaled equally, concatenated along the channel dimension, and normalized again to obtain a 1536-dimensional descriptor. Both coefficients are fixed at 0.5. Colored grids and vector segments illustrate spatial organization and channel provenance rather than measured feature values.

### Fig. 4. Construction and use of the normal reference memory

All fused patch descriptors from the K normal support images populate a fixed category-specific FAISS IndexFlatL2 memory. Each query descriptor retrieves its nearest support descriptor in feature space across all stored locations. Half of the squared Euclidean distance produces the patch score. The patch-score grid is resized to 448 × 448 and smoothed with σ = 4. The resulting map provides pixel-level scores and its spatial maximum provides the image-level score.

### Fig. S1. Matched comparison isolating the calibrated second representation

DCFnet and the DINO-only control use the same support-image identities, query images, DINO features, exact nearest-neighbor search, distance convention, post-processing, and evaluation resolution. They maintain separate memories constructed from normal support descriptors, while query descriptors enter their respective search operations. DCFnet uses 1536-dimensional fused descriptors, and the control uses 768-dimensional DINO descriptors.
