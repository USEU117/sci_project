## 本轮新定位的明确问题

### B01 FEAD 段落存在主谓一致错误

位置：第2节，原文以“Few-shot work has consequently…”开头的段落。

现文为“Hu et al. transform support features conditionally and constructs multi-frequency descriptors”。复数主语 Hu et al. 对应 transform 和 construct，第二个动词误用了 constructs。这是上轮加作者姓名时遗留的语言错误。

建议直接改为：

> Hu et al. transform support features conditionally and construct multi-frequency descriptors to compensate for sparse normal patterns in FEAD [10].

这项只涉及英文语法，不改变方法事实。对应老师对相关工作具体实例及英文表达的要求（9月5日49:12—54:17）。

### B02 相关工作有两句技术介绍缺少就近原始引文

位置：英文第3页、第2节。

“DINOv2 learns robust visual features without labels…”以及“CLIP learns aligned image and text embeddings…”两句后没有直接引文。原始来源已在参考文献表，分别是当前[26]和[27]，但直到3.3才正式引用。后一句 AnomalyDINO [3] 或 WinCLIP [16] 的引文不能自动当作前一句预训练模型的原始出处。

老师在9月1日强调原始来源，在9月5日23:47—27:37、34:22—36:58强调引文紧跟支持的陈述。上轮只检查编号首次出现顺序，未检查到这两句的来源位置。

建议：保留这两句时，在对应句末补原始来源，并按首次出现顺序重建全篇编号；或者精简这里的通用预训练介绍，将具体机制和原始引用集中在3.3。不能仅在此机械插入[26][27]后仍声称全文编号顺序无需调整。若选择补引文，相关工作不同来源会由25篇变为27篇；课堂的“约22—25篇”是数量建议，不能为了维持计数而省掉必要出处，应在段落精简时整体权衡。

### B03 DPAM 的首次出现早于全称解释

位置：英文第3页、第2节末部，“frozen DPAM-modified CLIP image encoder”；全称到3.3才出现。

对应9月5日14:11—18:16的缩写要求。摘要已压缩，并不意味着全文首次缩写都已处理。

建议：在第2节首次出现处展开 diagonally prominent attention map (DPAM)，同时明确来自 AnomalyCLIP；或在相关工作中写“the modified CLIP image encoder described in Section 3.3”，在3.3保留首次完整定义。后一种改法可避免相关工作塞入模块实现细节。中文对应位置也应同步处理。

### B04 支持图像与局部索引未完全服从新符号约定

位置：3.1符号约定、3.5式（6）及其后解释，英文第4和6页；图1也使用省略类别上标的支持图记号。

3.1说 p 和 q 分别表示查询与支持局部位置，但式（6）在构建支持记忆时仍使用 p；式（6）写带类别上标的支持图 x_i^c，随后的 G_D(x_i) 解释又省略了类别上标。它们在数学上可通过“局部哑变量”或“固定类别省略上标”解释，但当前稿没有给这种约定，因而未达到老师要求的统一程度。

建议：记忆库统一写为 M_c = ∪_{i=1}^{K}{f_{A,q}(x_i^c) : q ∈ G_D(x_i^c)}，后续解释和图源采用同一支持图记号。或者将3.1改为 p、q 是通用局部索引，并明确对比距离时的查询/支持角色。优先采用前一种方案，便于阅读；最终仍需用原生可编辑公式排版。不能只改 Word 正文而保留 PPT 图源的旧表示。

这项对应9月5日11:10—13:06、39:22—45:16的图文符号统一要求。上轮已经发现图源上标问题，本轮进一步定位到正文内部的索引和解释问题。

## 本轮补充的两项表述风险

### B05 Labels 的适用范围应收窄

位置：3.1，“Labels and masks are evaluation annotations, not inputs to … reference-memory construction…”；4.1.1又明确开发集比较参与融合系数取舍，支持图也必须是确认正常且属于相应产品类别的图像。

这不证明实验泄漏，但 Labels 的泛称容易使读者误以为正常性确认、类别身份乃至开发选择都没有使用标签信息。建议写明：正常支持选择需要确认正常性和类别；查询真值标签与像素掩码不输入特征提取、查询评分或外部验证参数选择；MPDD开发标签参与方法选择的事实仍在4.1.1保留。不要把“无目标域参数训练”写成“全过程无监督信息”。

这是技术表述澄清，不能按已证实的实验错误处理。

位置：摘要和 Data and Code Availability 只给仓库根地址。项目根 README 仍主要指向8月27日中文母稿；复现入口虽记录 SOURCE_COMMIT、VERSIONED_EVIDENCE.sha256 等材料，但当前论文没有给出与本稿对应的精确导航。

对应9月5日54:17及01:29:06—01:29:28的仓库维护要求。不能由此断言代码不存在，但读者从论文到正确实验与图表版本仍需额外辨认。

建议：在代码可用性中补充经核对的复现目录或版本说明入口，说明论文、结果包、图源各自对应关系；不要把旧 SOURCE_COMMIT 直接宣称为本轮英文稿的提交哈希。公开链接可达性及远端是否包含本轮文件，本轮未重新验证，保留为交付核验事项。

## 对消融计划还需做的一处纠偏

上轮把“joint normalization 的独立消融不足”与其他组件并列，容易让人误以为每一步都必须通过新增实验展示指标提升。老师要求的是有效验证模块作用，并未指定必须完成完整因子实验。

根据当前式（3）—（5），当两个分支描述符都为单位向量且系数固定为0.5时，拼接向量范数恒为1/√2。整体归一化只乘一个共同常数；在精确算术、保持平方欧氏评分与线性后处理等条件下，去掉这一步会按固定正比例缩放分数，不改变排序。因此，不能预设它会单独提高AUROC、AP或遍历阈值的最大F1。离散阈值实现、数值精度或后续处理引入的差异需要另行核对。

这是依据当前公式的分析，不是本轮新增实验结论。下一轮应优先评估会改变表征或邻居选择的对照，如分支归一化、DPAM路径、对齐方式及特征融合与分数融合；整体归一化主要解释其统一距离尺度的作用，必要时做一致性验证。
