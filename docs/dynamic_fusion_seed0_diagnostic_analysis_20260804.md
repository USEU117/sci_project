# 动态融合 seed-0 诊断分析（K=2/K=4）

更新日期：2026-08-04

## 1. 分析范围

本报告只使用 VisA seed 0 的 K=2/K=4 开发矩阵、路由输出和已完成的统一评测。测试标签只用于融合后的指标计算，没有进入路由器输入，也没有查看 VisA seed 1/2 或 MVTec 结果。

机器可读结果：`experiments/dynamic_fusion/20260804_diagnostics/report.json` 和 `category_diagnostics_k2_k4.csv`。

## 2. dynamic 低于最佳固定权重的类别

### K=2

- Image AUROC 明显下降：pcb4（-3.75 个百分点）、fryum（-2.26 个百分点）、pcb1（-2.03 个百分点）。
- Image AUROC 小幅下降：capsules、cashew、macaroni2、pipe_fryum。
- AUPRO 只有 chewinggum 低于最佳固定权重；其余 11 类提高，平均提高约 2.69 个百分点。
- K=2 的平均 Image AUROC 差值为 -0.50 个百分点，说明动态路由的主要问题在图像级排序，而不是区域定位。

### K=4

- Image AUROC 明显下降：pipe_fryum（-4.22 个百分点）、pcb4（-2.92 个百分点）、cashew（-2.08 个百分点）。
- AUPRO 下降的类别只有 candle、chewinggum、fryum；其余 9 类提高，平均提高约 5.28 个百分点。
- K=4 的平均 Image AUROC 差值为 -0.63 个百分点。

pcb4 和 pipe_fryum 是两个 shot 下都需要优先检查的类别。它们同时表现为图像级损失明显、AUPRO 改善，说明当前路由可能把像素定位有利的混合结果用于图像分数，导致整图排序被削弱。

## 3. 为什么视觉分支主导过多

当前路由器使用：

```text
visual_weight = softmax(-visual_uncertainty / temperature,
                         -text_uncertainty / temperature)
temperature = 0.20
min_weight = 0.05
```

实际结果显示：

- K=2 图像权重均值 0.823，中位数和 90 分位数都约为 0.95；视觉主导 1,631/2,162 张。
- K=4 图像权重均值 0.878，中位数和 90 分位数也约为 0.95；视觉主导 1,932/2,162 张。
- 两个 shot 都没有文本完全主导样本。

这不是因为代码无法选择文本，而是因为校准后的视觉不确定性整体低于文本不确定性，再加上温度 0.20 较小，softmax 很快饱和到 0.95 上限。换句话说，当前路由器的“置信度差异”被放大了。

## 4. 为什么文本分支没有完全主导

文本完全主导需要 `visual_weight <= 0.35`。但当前权重分布主要集中在高于 0.5 的区域，只有一部分样本落入 0.35—0.65 的加权融合区，没有样本低到 0.35 以下。

因此当前配置实际上更像：

```text
视觉主导 + 少量加权融合
```

而不是：

```text
视觉主导 / 文本主导 / 加权融合三路平衡切换
```

这会减少文本分支对图像级排序的影响，也解释了为什么 dynamic 的图像 AUROC 没有明显超过最佳固定权重。

## 5. 图像级权重和像素级权重应该分开

当前结果强烈支持分开设计：

- K=2 图像权重均值约 0.823，但像素权重均值约 0.356；
- K=4 图像权重均值约 0.878，但像素权重均值约 0.302；
- 两者的平均绝对差分别约为 0.484 和 0.580。

这说明“哪个分支更适合判断整张图”和“哪个分支更适合定位异常区域”不是同一个问题。当前实现虽然已经分别计算 image weight 和 pixel weight，但路由决定标签只使用 image weight；pixel weight 只参与像素图融合。这个设计可以保留，但需要在报告和论文中明确两种权重的语义不同。

## 6. 是否马上修改路由器

不建议现在直接改成最终版本。建议在 seed 0 开发协议中预登记以下小范围敏感性实验：

1. 温度：0.20、0.35、0.50；
2. 决策 margin：0.05、0.10、0.15；
3. 保留 `min_weight=0.05`，先不同时改变多个因素；
4. 图像分数和像素图分别保持独立权重；
5. 只比较 image AUROC、Pixel AUROC、Pixel AP、AUPRO 四项指标和路由比例。

预期判断方式：

- 如果温度提高后文本主导比例出现、Image AUROC 改善，说明原问题主要是 softmax 饱和；
- 如果 Image AUROC 仍下降但 AUPRO 保持改善，应考虑图像分数和像素图使用不同路由器，而不是继续调同一个权重；
- 如果调整 margin 只改变标签数量、不改变融合指标，说明 route label 本身不是核心问题，真正应分析连续权重。

这些实验仍然只用 seed 0，不构成最终泛化结果。只有在 seed 0 上预先登记的方案中选定一个结构后，才可以冻结并进入 seed 1/2 和 MVTec 最终验证。

## 7. 当前建议

当前最稳妥的设计方向是：

- 保留连续图像权重和连续像素权重；
- 提高温度，避免视觉权重长期饱和到 0.95；
- 暂时不把“visual/text/weighted”三个字符串标签当作核心输出，核心输出应是连续权重；
- 对 pcb4、pipe_fryum、fryum、pcb1、cashew 做优先失败案例可视化；
- 不使用测试集整体统计量修正权重；
- 在 seed 0 小范围敏感性实验结束前，不冻结路由器。
