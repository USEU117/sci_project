## 4 本轮纠正的关键事实

1. **融合维度为 1536，不是 1152。** 两个输出均为 768 维；CLIP Transformer 内部宽度为 1024，投影后的局部输出为 768，不能混为一谈。
2. **两个 patch 边长都是 14。** 不同网格来自输入分辨率和宽高比处理：CLIP 为 518×518、37×37；DINO 短边 448，原生网格并非所有类别都严格 32×32。
3. **固定视觉融合，不是动态路由或文本推理。** `anomalyclip_text` 是历史目录名。导出脚本加载提示检查点，但保留路径只调用图像编码器；不能写成视觉分支受提示训练效果已经得到因果证明。
4. **后处理先双线性缩放到 448，再高斯平滑。** 个别历史文字的顺序与实际 `dists2map` 不一致，本稿按实现表述。
5. **FAISS 返回平方距离。** `distance / 2` 不是普通欧氏距离再除 2。本文明确单位向量情况下与余弦距离的关系。
6. **联合距离在同一个候选正常 patch 上组合两分支证据。** 这与两个分支分别选最近邻后再平均异常图不同。式（5）为现有实现的数学说明，不是新做的机制实验。
7. **bootstrap 旧 Markdown 的“类别内分层”描述不准确。** 实际图像重采样使用步长采样后仍含正像素的逐图 P-AP 差值，没有类别分层；类别 bootstrap 才对应主表宏平均的解释单位。
8. **0.4146 秒是阶段均值之和。** GPU 两分支和 CPU 融合搜索分进程测量；2.412 图/秒是该和的倒数。没有据此宣称整套生产系统实测吞吐。
9. **GPU/RAM 峰值是特定阶段或进程指标。** 不是两个模型和所有缓存同时驻留的整体峰值。CPU/RAM 为本次写稿时补核，未伪装为旧实验自动记录。
10. **324 指的是类别/配置文件数。** 每个紧凑文件可以包含多张测试图，不能写成“只有 324 张测试图像”。
11. **成功失败案例身份与选择规则对齐。** leather 失败样例为 `leather/test/poke/016.png`；成功案例按指定类别最大逐图增益选取，不能写成随机或中位案例。
12. **匹配 DINO-only 不等于外部 AnomalyDINO。** 前者是 ViT-B/14 同管线对照，后者项目运行是 ViT-S/14 与自身管线。DCFnet 优于前者，不能因此声称超过后者。
13. **SubspaceAD 作者存在官网元数据与正文拼写差异。** 官方页面 BibTeX 写 Bondarau，官方论文 PDF 首页及作者 arXiv 写 Bondarev。本稿采用论文首页的 Bondarev，保留该核对说明。
