## 二、先用通俗语言说明：这篇论文到底讲了什么

工业异常检测面对的是一种特殊问题：工厂很容易收集大量合格产品，但真正的缺陷样本数量少、类型不完整，而且新缺陷可能从未出现过。因此，系统不能只学习“某几种已知缺陷长什么样”，而需要先学习“正常产品长什么样”，再把偏离正常模式的位置标记为异常。

本研究从每个类别仅有 1、2 或 4 张正常参考图的场景出发。核心问题不是重新训练一个大型模型，而是研究两种已经训练好的视觉表征能否互补：

- DINOv2 擅长从图像中提取稳定的结构、纹理和局部视觉模式；
- AnomalyCLIP 的图像编码器来自视觉—语言预训练体系，其视觉空间与 DINOv2 不同，可能保留另一类局部线索。

本文将同一图像分别送入两个冻结编码器，取得每个局部 patch 的 768 维特征。由于两个编码器的 patch 网格不同，先把 AnomalyCLIP 的视觉特征网格插值到 DINOv2 网格。随后分别对两个分支做 L2 归一化，以等权方式拼接为 1536 维特征，再整体归一化。每个类别的 K 张正常参考图提供正常 patch，所有正常 patch 构成记忆库。测试图中的每个 patch 在记忆库里寻找最近邻，它与最近正常 patch 的距离就是局部异常程度。最后把低分辨率 patch 分数图平滑并上采样为像素级异常图。

这套方法没有训练参数，不学习路由器，也不根据测试标签调权重。最终权重固定为 0.5/0.5，最近邻数固定为 1。它的价值不是提出复杂的新网络，而是证明：在严格 normal-only、少样本、无测试标签调参的条件下，两种异构但互补的冻结视觉 patch 表征，通过极简的特征级融合，就能在四个数据集上稳定改善像素级异常定位。

与此同时，论文并不回避失败：融合并非在每个类别和每个指标上都有帮助。例如 MVTec AD 的 leather、VisA 的 chewinggum 等类别存在稳定负迁移；BTAD 的 Pixel-AP 提升，但 Image-AP 和 Image-F1-max 下降。论文因此讨论“何时互补、何时融合会稀释强视觉特征”，而不是宣称一个全面优于所有方法的万能模型。

## 三、这项工作具体做了什么

本项目完成的不只是一次模型运行，而是一套从方法探索到可复现交付的完整研究流程。

第一，建立了统一的少样本实验协议。四个数据集都按照 1/2/4-shot 正常参考设置运行，每个 shot 使用 3 个随机种子。数据划分、参考图 ID、模型权重、评估器和输出均有固定记录。MPDD 被作为开发集；参数冻结后，VisA 用作域内冻结验证，BTAD 和 MVTec AD 用作外部冻结验证。

第二，建立了公平的 matched control。论文的主要因果比较不是 A1 对不同代码库中某个公开方法的最好数字，而是 A1 与完全相同管线中的 feature-DINO-only KNN 比较。两者使用相同参考图、相同 DINO 特征、相同 KNN、相同后处理和相同评估器，唯一差别是 A1 是否加入对齐后的 AnomalyCLIP 视觉 patch 特征。因此，`A1 − matched DINO-only` 更接近融合本身带来的净贡献。

第三，进行了动态融合和复杂路线探索，但用实验结果主动停止了无价值的扩展。早期 V3.3 使用测试 mask 做 z-score 校准，后来被识别为泄漏，只作为污染的开发记录保留；V3.4、V4、Subspace-style 和 Route-D 等路线分别经过固定 Gate 审计，没有稳定超过强视觉锚点或固定融合，因此没有包装成正结果。最终模型回到最简单、最可复现的等权固定融合。

第四，完成了跨数据集、跨 shot、跨 seed 的完整验证。A1 主矩阵共有 4 个数据集 × 3 个 seed × 3 个 shot，即 36 个配置。每份报告包含 Image-AUROC、Image-AP、Image-F1-max、Pixel-AUROC、Pixel-AP 和 Pixel-AUPRO 六项指标。

第五，完成了统计和失败边界分析。对 A1 与 matched DINO-only 的 Pixel-AP 差值进行了配对图像 bootstrap 和类别 bootstrap，并保留 2000 次重采样的 95% 区间。进一步统计了负增益类别、逐图失败样例及固定选择的成功/失败定性图。

第六，完成了效率和资源审计。报告了 0 训练参数、正常记忆库规模、稳态端到端延迟、吞吐、显存和进程 RAM，而不是把包含一次性模型加载的 smoke 时间误写成稳定吞吐。

第七，完成了可复现投稿包。包内包含冻结配置、split 和权重哈希、324 个可重放 compact patch maps、独立 CPU 重算程序、逐配置报告、统计表、失败样例、协议公平性表以及 SHA256 完整性校验，但不重新分发数据集原图和第三方权重。

## 四、摘要初稿

工业异常检测通常只能获得少量正常参考图，而异常样本稀缺且类型开放。近年来，冻结视觉基础模型和视觉—语言预训练模型分别表现出较强的局部表征能力，但在严格 normal-only 协议下，异构 patch 表征能否以简单、可复现的方式形成稳定互补，仍缺少充分的跨数据集验证。本文提出一种零训练的冻结双视觉编码器特征融合方法。该方法分别从 DINOv2 ViT-B/14 和 AnomalyCLIP ViT-L/14@336 图像塔提取 768 维 patch 特征，将后者的空间网格对齐到前者，对两个分支分别进行 L2 归一化后等权拼接为 1536 维表示，并利用 K 张正常参考图构建 KNN 正常记忆库。测试 patch 到最近正常 patch 的距离用于生成像素级异常图。整个推理过程不使用显式文本特征、动态路由、参数训练或测试标签校准。

我们在 MPDD、BTAD、VisA 和 MVTec AD 上按照 1/2/4-shot、3-seed 协议进行评估，并采用相同管线下的 DINO-only KNN 作为 matched control。相较于该控制方法，所提出的固定融合在四个数据集的 9 个 seed/shot 配置中均获得正的平均 Pixel-AP 增益，数据集级增益分别为 0.0258、0.0249、0.0524 和 0.0320。完整六指标结果表明，融合同时改善了四个数据集的 Pixel-AUROC、Pixel-AP 和 Pixel-AUPRO，但 BTAD 的 Image-AP 和 Image-F1-max 分别下降约 0.0131 和 0.0237，说明局部定位互补并不必然转化为图像级决策增益。逐类别分析进一步发现 MVTec leather、VisA chewinggum 等稳定负迁移类别。实验还表明，更复杂的动态路由未能稳定超过等权固定融合。本文的主要贡献是一种简单的冻结双视觉 patch 融合基线，以及一套包含防泄漏协议、matched control、跨数据集验证、统计区间、失败边界和可重放证据的严谨评估框架。

关键词：工业异常检测；少样本异常检测；异常定位；DINOv2；AnomalyCLIP；特征融合；正常记忆库；可复现性

## 五、Introduction 初稿

工业视觉检测是智能制造质量控制的重要组成部分。与常规图像分类不同，生产环境中的缺陷往往稀有、开放且不断变化，许多缺陷只占图像中的小区域。企业通常能够持续收集合格产品图像，却难以为所有可能的异常类型建立规模充足且像素级标注的数据集。因此，工业异常检测系统不仅需要判断一张图像是否异常，还需要准确定位缺陷区域，并且应当在只有少量正常参考图的冷启动条件下工作。MVTec AD、VisA、MPDD 和 BTAD 等数据集推动了这一研究方向，但不同数据规模、对象类型和评估协议也使跨方法比较容易受到数据划分和实现差异影响。

基于正常样本的 patch-level 最近邻方法为这一问题提供了直观而有效的解决思路。典型方法首先利用预训练网络把正常图像转换为局部特征集合，再把测试 patch 与正常记忆库进行比较。PatchCore 证明了正常 patch memory bank 在工业异常定位中的有效性。随着视觉基础模型的发展，DINOv2 等自监督视觉模型能够提供更加通用的局部结构表征；AnomalyDINO 等方法进一步表明，冻结 DINOv2 patch 特征本身就能形成很强的 training-free 少样本异常检测器。近期 SubspaceAD、FastRef 和 DCP-SFR 等工作也分别从正常子空间、参考原型细化和缺陷线索保留的角度强化了纯视觉路线。这些进展意味着，任何融合方法都不能只因为使用多个分支便默认具有优势，而必须与强视觉表征进行严格的 matched comparison。

另一条研究路线利用 CLIP 的视觉—语言预训练知识改善异常检测。WinCLIP 将文本 prompt、窗口特征和正常参考结合起来，AnomalyCLIP 通过 object-agnostic normal/abnormal prompts 改善异常语义对齐，PromptAD 则在 only-normal 条件下学习目标类别 prompt。AA-CLIP、FAPrompt、ReMP-AD 等近期方法继续从异常感知对齐、细粒度异常 prompt 和检索增强融合等方向扩展这一范式。这些研究说明视觉—语言预训练空间可能包含不同于自监督 DINO 的特征信息，但文本概率、视觉距离和局部 patch 特征具有不同统计含义。若直接混合未经校准的异常分数，或者利用测试集统计选择权重，容易产生不稳定提升甚至数据泄漏。

由此产生本文的核心研究问题：在不学习路由器、不使用测试标签、不改变正常参考协议的情况下，DINOv2 与 AnomalyCLIP 图像塔的局部视觉特征是否具有可重复的互补性？进一步地，如果互补性存在，它是否能在多个 shot、多个随机参考选择和多个数据集上稳定出现？哪些类别会受益，哪些类别会发生负迁移？简单固定融合与复杂动态融合相比是否已经足够？

为回答这些问题，本文构建了一个冻结双视觉编码器的特征级融合方法。DINOv2 和 AnomalyCLIP 图像塔分别产生局部 patch 表征；在空间对齐和分支内归一化后，两组特征以固定等权方式拼接，并由少量正常参考图构建最近邻记忆库。该方法没有任何训练参数，推理时不调用文本编码器，不根据类别或测试样本动态改变权重。我们选择等权融合，是因为开发集权重扫描中 0.4 与 0.5 的差距仅约 0.0009 Pixel-AP，处于噪声量级；保留对称的 0.5 可以减少超参数自由度，并降低对开发集的过拟合风险。

实验采用严格的数据角色和冻结流程。MPDD 用于方法开发，方法和超参数冻结后再在 VisA、BTAD 和 MVTec AD 上验证。每个数据集均覆盖 1、2 和 4 张正常参考图以及 3 个随机种子。主要比较对象是在同一数据、同一参考图、同一 KNN 和同一评估器下运行的 DINO-only 控制方法。实验结果显示，固定融合在四个数据集的全部 9 个 seed/shot 配置上均获得正的平均 Pixel-AP 增益。与此同时，完整指标和类别分析揭示了明确边界：A1 在 MVTec AD 和 VisA 上没有超过 AnomalyDINO 的宏平均结果；BTAD 的图像级 AP/F1 下降；部分纹理类和细粒度缺陷类别持续出现负迁移。因此，本文不将方法描述为全面 SOTA，而将贡献定位为：证明简单的异构冻结视觉 patch 融合能够稳定增强像素定位，并给出其可复现条件与失败边界。

本文的主要贡献如下：

1. 提出一种零训练、无动态路由的双视觉编码器 patch 特征融合方法，在冻结 DINOv2 与 AnomalyCLIP 图像塔之间进行空间对齐、分支归一化和等权拼接，并使用正常记忆库完成少样本异常定位。
2. 设计严格的 normal-only、1/2/4-shot、3-seed、跨四数据集验证协议，并使用 matched DINO-only 控制隔离融合本身的净收益。
3. 提供完整的六指标、bootstrap、逐类别负迁移和成功/失败案例分析，说明稳定结论适用于像素级定位，而不是所有图像级指标。
4. 建立防泄漏与可复现证据链，公开冻结配置、输入哈希、compact maps、CPU 重算程序和失败路线记录，使正结果和负结果均可审计。

## 六、Related Work 初稿

### 6.1 基于正常记忆库的工业异常检测

基于正常样本建模的方法通常假设训练或参考阶段只能观察合格品。PaDiM 通过局部特征分布描述正常模式，PatchCore 则保留具有代表性的正常 patch memory bank，并用最近邻距离产生异常分数。这类方法训练需求低、解释直观，尤其适合 few-normal-shot 场景，但性能高度依赖预训练特征、参考图选择、空间尺度和 memory bank 构造。本文沿用正常 patch 最近邻框架，但不进行 coreset 压缩，重点研究两种冻结基础模型特征在相同 reference-conditioned KNN 管线中的互补性。

### 6.2 冻结视觉基础模型与少样本异常检测

DINOv2 提供了具有较强局部结构感知能力的自监督视觉特征。AnomalyDINO 使用冻结 DINOv2 patch 表征和正常最近邻实现 training-free 少样本异常检测，构成本文必须面对的强视觉锚点。UniVAD、SubspaceAD、FastRef 与 DCP-SFR 分别从跨域统一检测、正常子空间重建、查询相关原型细化和缺陷线索保护等方向进一步提升视觉路线。这些工作说明，性能提升可能主要来自更好的视觉正常性建模，而非更复杂的末端融合。因此，本文既报告与公开方法的协议对照，也把 matched DINO-only 作为判断融合有效性的首要基线。

### 6.3 视觉—语言异常检测

CLIP 通过大规模图文对比预训练建立视觉和语言的共享表征空间。WinCLIP 将 prompt ensemble 和窗口级视觉特征用于 zero-/few-shot 异常检测，AnomalyCLIP 学习对象无关的正常与异常 prompt，PromptAD 则利用少量目标正常图进行 prompt 学习。AA-CLIP、FAPrompt、FB-CLIP 等工作进一步处理异常感知对齐、细粒度异常语义和前景—背景干扰。与这些方法不同，本文最终推理不使用文本 token 或文本相似度。AnomalyCLIP 仅提供其预训练图像塔的视觉 patch 特征。因此，本文方法应归类为 dual-encoder visual feature fusion，而不是文本引导或多模态推理方法。

### 6.4 融合、动态路由与本文差异

近期工作开始研究多尺度、检索增强和专家路由，例如 ReMP-AD 融合检索得到的类内 token 与视觉—语言先验，MoECLIP 将不同 patch 路由到专门化 LoRA experts。这些方法表明动态适配具有潜力，但同时引入训练、协议和信息边界差异。本文早期也研究了基于可靠性或不确定性的动态融合，但开发集上的动态方法相对固定融合仅获得约 0.0009 的平均增益，胜出比例为 4/9，后续可预测性门也未通过。因此本文选择把复杂动态路线作为负结果和设计依据，而不作为主方法。本文关注的问题更窄：不训练、不路由时，简单的异构视觉 patch 拼接是否已经能够形成跨数据集稳定收益。

## 七、方法初稿

### 7.1 问题定义

设一个工业类别只有 K 张正常参考图，K 属于 {1,2,4}。参考集合记为 R，测试图记为 x。目标是在没有异常训练样本的条件下输出像素级异常图 A(x)，并通过异常图的最大响应得到图像级异常分数。所有编码器参数在实验中保持冻结。

### 7.2 双分支视觉特征提取

对输入图像分别使用两个编码器：

- DINO 分支为 DINOv2 ViT-B/14，输入尺度为 448，输出每个 patch 768 维的局部特征；
- CLIP 视觉分支为 AnomalyCLIP ViT-L/14@336 图像塔，实际输入尺度为 518，通过其视觉层抽取每个 patch 768 维的特征。

需要强调的是，历史目录名中出现 `anomalyclip_text`，但这是早期命名遗留。最终 A1 不使用文本特征，两个分支都输出视觉 patch embedding。

### 7.3 空间对齐与固定融合

两个编码器产生的 patch 网格不同。设 DINO 网格为 Hd×Wd，CLIP 网格为 Hc×Wc。本文使用双线性插值将 CLIP patch feature map 对齐到 DINO 网格。对每个空间位置 p，先分别做 L2 归一化：

`d_hat(p) = d(p) / ||d(p)||2`，`c_hat(p) = c(p) / ||c(p)||2`。

之后进行固定等权拼接：

`z(p) = Normalize([0.5 d_hat(p); 0.5 c_hat(p)])`。

由于两个分支均为 768 维，拼接后的维度为 1536。等权设计避免为不同数据集或类别选择额外权重。虽然开发阶段扫描到 w=0.4 的单点结果略高，但相对 w=0.5 的差距只有约 0.0009 Pixel-AP，因此最终冻结 w=0.5。

### 7.4 正常记忆库与异常评分

对每个类别，把 K 张正常参考图的全部融合 patch 特征加入正常记忆库 M。测试图每个融合 patch zq(p) 在 M 中查找欧氏距离最近的正常 patch：

`s(p) = 0.5 × min_{m∈M} ||zq(p) − m||²`。

实现采用 FAISS `IndexFlatL2`，最近邻数 k=1。由于归一化向量的平方欧氏距离与余弦差异单调对应，`distance/2` 可作为局部异常分数。所有 patch 分数组成低分辨率异常图，经 sigma=4 的高斯平滑和双线性插值恢复到 448×448。

### 7.5 Matched DINO-only 控制

为了区分“融合收益”和“重新实现收益”，本文设置 matched DINO-only。它与 A1 使用完全相同的参考图、DINO patch、正常记忆库、k=1、距离定义、平滑、上采样和评估器，只移除 CLIP 视觉分支。论文的主要增益定义为：

`ΔPixel-AP = Pixel-AP(A1) − Pixel-AP(matched DINO-only)`。

### 7.6 防泄漏约束

方法选择只能使用开发阶段允许的信息。测试标签、测试 mask、测试集统计、测试正常样本选择和按测试类别调节权重均被禁止。历史 V3.3 曾使用测试 mask 进行 z-score 校准，该结果被标记为 `paper_eligible=false`，不进入本文主证据。最终 A1 的权重、归一化、KNN 和后处理在外部数据集验证前冻结。

## 八、实验设计初稿

### 8.1 数据集与角色

实验覆盖 MPDD、BTAD、VisA 和 MVTec AD。MPDD 用作开发数据集；VisA 被标记为域内冻结验证，因为使用的 AnomalyCLIP checkpoint 与 VisA 存在源域关系；BTAD 和 MVTec AD 用作外部冻结验证。该角色划分用于限制结论：VisA 的提升可以证明冻结配置的域内稳定性，但不能被包装为完全独立的外部泛化证据。

### 8.2 Few-shot 设置

每个类别从正常训练图中选择 K=1、2、4 张参考图，并使用 seed=0、1、2 产生三组固定采样。因此每个数据集有 9 个 seed/shot 配置，四数据集共 36 个配置。9 个配置共享相同测试集，只改变正常参考图，不能视为 9 个独立数据集。

### 8.3 评价指标

图像级指标包括 Image-AUROC、Image-AP 和 Image-F1-max；图像分数由异常图最大池化得到。像素级指标包括 Pixel-AUROC、Pixel-AP 和 Pixel-AUPRO。Pixel-AP 是本文判断局部缺陷定位互补性的主要指标，因为工业数据中正常像素远多于异常像素，AP 能更直接反映异常区域排序质量。所有像素指标使用同一冻结评估器，并在 stride=8 条件下计算。

### 8.4 对照方法与公平性

主要控制为 matched feature-DINO-only KNN。跨方法表还整理 PatchCore、WinCLIP+、AnomalyDINO、PromptAD、AnomalyCLIP、ReMP-AD 和 AdaptCLIP，但明确区分其协议：PromptAD 使用目标正常图进行 prompt tuning；AnomalyCLIP 为 zero-shot；ReMP-AD 使用官方 source-domain training；AdaptCLIP 使用源域 adapter checkpoint。这些结果用于定位方法水平，不能替代 matched control，也不能无条件混成同一排行榜。

### 8.5 统计分析

对每个配置的 Pixel-AP 差值进行 B=2000 的 bootstrap。图像 bootstrap 在类别内对异常测试图配对重采样，类别 bootstrap 则重采样类别。所有 36 个配置同时对照历史 P0 表，误差均小于 5×10^-4。报告 dataset×shot 的三 seed mean±std，同时保留逐配置和逐类别结果。

### 8.6 效率设置

模型不训练，训练参数为 0。稳态 benchmark 使用 MVTec bottle、seed0、1-shot，模型预热 3 次后重复 30 次。测量 DINO 特征提取、CLIP 特征提取、特征对齐与 concat+KNN，以及进程 RAM。该测量排除一次性模型加载时间。

## 九、结果与分析初稿

### 9.1 相对 matched DINO-only 的主要结果

在四个数据集上，A1 的平均 Pixel-AP 均高于 matched DINO-only：MPDD 从 0.3304 提升到 0.3562，增益为 0.0258；BTAD 从 0.6206 提升到 0.6455，增益为 0.0249；VisA 从 0.3201 提升到 0.3725，增益为 0.0524；MVTec AD 从 0.5226 提升到 0.5546，增益为 0.0320。每个数据集的 9 个 seed/shot 配置平均增益均为正，说明收益不是由单一 shot 或单一随机参考选择造成。

| 数据集 | A1 Pixel-AP | DINO-only Pixel-AP | ΔPixel-AP | 9配置情况 |
|---|---:|---:|---:|---|
| MPDD | 0.3562 ± 0.0350 | 0.3304 ± 0.0345 | +0.0258 | 9/9 正 |
| BTAD | 0.6455 ± 0.0124 | 0.6206 ± 0.0183 | +0.0249 | 9/9 正 |
| VisA | 0.3725 ± 0.0246 | 0.3201 ± 0.0278 | +0.0524 | 9/9 正 |
| MVTec AD | 0.5546 ± 0.0196 | 0.5226 ± 0.0184 | +0.0320 | 9/9 正 |

从 shot 维度看，MPDD 的平均增益在 1/2/4-shot 下分别为 +0.0210、+0.0277 和 +0.0288；BTAD 为 +0.0258、+0.0239 和 +0.0250；VisA 为 +0.0558、+0.0523 和 +0.0490；MVTec AD 为 +0.0348、+0.0311 和 +0.0300。融合收益没有随着参考图增加而单调扩大。一个合理解释是：更多正常图会同时增强两个方法的正常覆盖，使单分支 DINO 的不足有所缩小；融合的主要价值在极少参考条件下可能更明显。不过这一解释属于结果推断，不能写成已直接验证的机制。

### 9.2 完整六指标结果

A1 在四个数据集的 Pixel-AUROC、Pixel-AP 和 Pixel-AUPRO 上都高于 matched DINO-only。这支持“融合改善像素定位”的中心结论。图像级结果则更复杂：MPDD、VisA 和 MVTec AD 的三个图像指标均改善；BTAD 的 Image-AUROC 轻微提高 0.0039，但 Image-AP 下降 0.0131，Image-F1-max 下降 0.0237。

这一现象说明，局部 anomaly map 更准确，并不保证最大池化后的图像分数具有更好的全局排序或阈值行为。融合可能提高某些真实缺陷区域的响应，同时也抬高正常区域或困难正常样本的最大响应，进而影响图像级 precision-recall。后续正式论文应把 BTAD 作为主要限制讨论，而不能只选择有利指标。

### 9.3 与其他方法的关系

在 MVTec AD 和 VisA 的统一宏平均表中，AnomalyDINO 在多数指标上仍然最强。A1 通常位于第二梯队前列，并超过 PatchCore、WinCLIP+、PromptAD 等本地统一协议结果，但没有全面超过 AnomalyDINO。例如 MVTec AD 上 A1 的 Pixel-AP 为 0.5546，而 AnomalyDINO 为 0.5710；VisA 上分别为 0.3725 和 0.4117。因此，本文不能宣称新的 SOTA。

这里并不存在逻辑矛盾：本文 matched DINO-only 使用 ViT-B/14 特征和严格相同的 A1 管线，用于隔离融合贡献；跨方法 AnomalyDINO 使用项目实际的 ViT-S/14 official-style runner，属于方法级参照。A1 对 matched control 的稳定提升证明两种表征具有互补性，但它没有证明这套简单融合优于所有经过专门设计的强视觉异常检测算法。

### 9.4 逐类别成功与失败边界

36 个配置中共观察到 65 次类别级负增益，涉及 10 个去重 dataset@category。持续负迁移最明显的类别包括 MVTec leather（9/9 负，平均 -0.0428）、VisA chewinggum（9/9 负，平均 -0.0386）、MVTec hazelnut（9/9 负，平均 -0.0297）、VisA candle（9/9 负，平均 -0.0198）和 MPDD bracket_brown（9/9 负，平均 -0.0051）。另一方面，VisA pcb1、cashew、MVTec toothbrush、MPDD metal_plate 等类别获得明显正增益。

定性案例进一步展示这种差异。VisA cashew 的一个固定成功样例中，Pixel-AP 从 0.0734 提高到 0.6758；MVTec toothbrush 从 0.4217 提高到 0.7444。相反，MVTec leather 的固定失败样例从 0.9294 降到 0.2345，VisA chewinggum 从 0.2769 降到 0.1124。这说明 CLIP 视觉表征有时能补充 DINO 未充分响应的对象或缺陷线索，但对规则纹理、细微表面变化或背景相似区域，也可能引入不相关响应并稀释 DINO 的优势。

对失败原因的表述必须保持谨慎。现有证据能够证明“哪些类别稳定负迁移”，但没有通过因果实验证明具体原因是纹理、尺度还是预训练域偏差。因此正式论文可以把上述机制作为解释性假设，并结合热力图讨论，而不能写成已被严格证明的因果结论。

### 9.5 为什么最终没有采用动态融合

开发阶段曾尝试根据分支可靠性、熵或其他局部信息动态调整权重。结果显示，动态方案相对等权固定融合的平均增益约为 0.0009，且只在 4/9 配置中胜出；后续 Route-D 的局部“何时应该纠正 A1”可预测性检验也未达到预设门槛。另有 V3.3 校准方案使用测试 mask，被判定为泄漏并从论文证据中移除。

这些负结果带来一个重要设计结论：两分支确实具有总体互补性，但当前无标签可靠性特征不足以稳定预测每个 patch 应该信任哪个分支。既然复杂路由没有产生可重复收益，固定等权融合更符合奥卡姆原则，也更容易审计和复现。论文可以把这一过程放在消融或 Discussion 中，但不要把失败的动态路由写进方法名称。

### 9.6 效率与资源

A1 不进行参数训练。MVTec bottle s0/k1 的稳态测量中，DINO 特征提取约 0.0626 秒/图，CLIP 特征提取约 0.3049 秒/图，对齐、拼接和 KNN 约 0.0471 秒/图，总计约 0.4146 秒/图，对应 2.412 图/秒。峰值显存约 2073 MB，峰值进程 RAM 约 3980.9 MB。

计算开销主要来自 CLIP 图像编码器，而不是 concat 或 KNN。memory bank 随 shot 数近似线性增长。例如 MPDD 1-shot 的 A1 bank 为 6144 个 1536 维 patch，float32 大小约 37.75 MB；MVTec AD 4-shot 为 61440 个 patch，约 377.49 MB。该方法在 6 GB 显存设备上可以运行，但其速度明显不是实时检测水平，部署时仍可考虑特征蒸馏、memory bank 压缩或近似近邻搜索。

## 十、Discussion 初稿

### 10.1 本文真正证明了什么

本文最有力的结论不是“两个大模型拼起来一定更强”，而是以下更严格的陈述：在冻结编码器、固定等权、normal-only reference memory bank 和无测试标签调参的条件下，DINOv2 与 AnomalyCLIP 图像塔的 patch 特征在四个数据集上对 Pixel-AP 具有稳定平均互补性。该结论由 matched control、36 个配置、外部冻结验证、完整指标和失败案例共同支持。

### 10.2 为什么简单方法仍有论文价值

方法结构简单并不等于研究问题简单。当前异常检测文献包含大量不同 backbone、训练方式、prompt 学习、源域 checkpoint 和测试时适配协议，单点高分很难判断提升来自哪里。本文通过控制变量、冻结策略和证据审计，把问题收缩为“第二种视觉表征是否在相同 KNN 中提供增量信息”。四数据集稳定的 Pixel-AP 增益说明答案总体为是；负迁移和动态路由失败又说明这种互补存在边界。对于偏应用和实验验证导向的 SCI 四区期刊，这种完整、诚实、可复现的研究可以形成可防守贡献。

### 10.3 与视觉—语言融合叙事的区别

AnomalyCLIP 的来源是视觉—语言模型，但 A1 推理没有文本输入。因此论文不能声称“视觉与文本动态融合”。更准确的说法是：两个具有不同预训练目标的视觉编码器产生异构 patch 表征，其中一个视觉编码器继承自视觉—语言预训练框架。论文可以在动机中讨论 vision-language pretraining 可能带来的语义迁移，但方法分类仍应是双视觉编码器特征融合。

### 10.4 负结果的意义

负结果不是项目失败，而是定义了适用范围。动态方案未稳定胜出，说明无需为复杂性本身付出代价；某些类别持续下降，说明固定融合仍不能识别所有局部冲突；BTAD 图像级指标下降，说明定位与分类需要不同的 aggregation 设计。这些发现可指导未来工作研究无标签冲突检测、类别不可知的可靠性估计或分别优化 pixel-level 与 image-level scoring，但不要求本文继续扩展算法。

## 十一、局限性初稿

本文仍存在以下限制。

第一，A1 没有全面超过当前强视觉方法。AnomalyDINO 在 MVTec AD 和 VisA 的多数宏平均指标上更强，因此本文贡献应定位为稳定增量、严谨验证与失败边界，而不是 SOTA。

第二，AnomalyCLIP 图像分支增加了计算和内存开销。稳态速度约 2.412 图/秒，CLIP 特征提取占主要时间，不适用于未经优化的高速产线实时部署。

第三，固定等权融合存在类别级负迁移。MVTec leather、VisA chewinggum 等类别说明异构表征也会相互干扰；当前实验只能识别失败类别，还不能在无标签条件下可靠地预判失败。

第四，VisA 属于域内冻结验证，不能与 BTAD/MVTec 的外部冻结角色等同。MPDD 和 BTAD 缺少与所有外部方法完全同协议的完整 baseline 矩阵，因此不能在这两个数据集上宣称全面 SOTA。

第五，实验聚焦四个经典 2D 工业异常数据集，尚未覆盖 Real-IAD 等更大规模、多视角或 3D 场景。论文可以把它列为未来验证方向，但不需要作为当前投稿前硬门槛。

第六，图像级分数采用 anomaly map 最大池化，可能放大局部假阳性。BTAD 的图像级 AP/F1 下降表明，定位图与图像判定也许需要不同的稳健聚合策略。

## 十二、结论初稿

本文研究了严格少样本 normal-only 条件下两种冻结视觉 patch 表征的互补性。我们将 DINOv2 ViT-B/14 与 AnomalyCLIP ViT-L/14@336 图像塔的局部特征进行空间对齐、分支归一化和等权拼接，并使用正常参考 patch 构建 KNN 记忆库。该方法不训练参数、不使用显式文本特征、不进行动态路由，也不依赖测试标签校准。

在 MPDD、BTAD、VisA 和 MVTec AD 的 1/2/4-shot、3-seed 实验中，固定融合相对 matched DINO-only 在四个数据集的全部 seed/shot 配置上都获得正的平均 Pixel-AP 增益。与此同时，完整指标和失败边界分析表明，融合不是全面有效：BTAD 图像级 AP/F1 下降，一些类别持续负迁移，A1 也没有全面超过 AnomalyDINO。更复杂的动态融合未产生稳定收益，因而最终方法保留简单固定设计。

这些结果说明，在强视觉基础模型已经具备良好性能的情况下，异构冻结视觉表征仍可通过极简融合增强像素级异常定位，但可靠性必须通过严格 matched control、跨数据集冻结验证和负迁移分析来证明。本文同时提供可审计的配置、哈希、compact maps、统计表和重算程序，为工业异常检测中的可复现融合研究提供一个诚实基线。
