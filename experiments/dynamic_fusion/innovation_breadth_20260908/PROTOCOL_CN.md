# 广度探针组合立项与预注册（2026-09-08）

目标：在冻结特征 + 真实 MPDD 门口径下，尽量宽地扫不同机制族（不是同一变体的细调），每个候选独立可证伪；通过者才可能成为后续验证 lead，失败即归档。不引入训练、不读新数据、不改冻结 A1。

## 硬约束（沿用全部纪律）
- 数据：A1 冻结特征缓存只读（seed0，k2 与 k4）；真实 MPDD test 只读评价；无 /test/good 进 memory；无 test 标签拟合/选类/路由。
- 口径：与 A1 完全一致（1−max-cos → dists2map 448 → Pixel-AP/AUROC/AUPRO，stride 8）；control 必须复现冻结宏（k2 0.3437 / k4 0.3883）。
- 门（两 shot 均须满足才算该族 PASS，与 doc36 相同结构）：族 lead 宏 ΔAP ≥ **+0.01**；lead 最差类 ΔAP ≥ **−0.03**；lead 宏 ΔAUROC ≥ **−0.005**。
- lead 定义（预注册，防止按结果挑）：每族内预注册的 α/θ 变体，取**宏 ΔAP 最大者**为该族 lead；对 lead 判门并同时报告其余变体。
- 未过门 → 归档；过门 → 进入下一层验证（跨 shot 复现 + 简单控制对照）后才可谈论文。

## 候选（10 个配置 + control，覆盖 6 个机制族）
| ID | 机制族 | 描述 | 预注册变体 |
|---|---|---|---|
| C0 | control | A1 concat 冻结路径 | — |
| CS | 特征通道标定 | 对 concat 特征按**参考集**逐通道标准化（mean/std fit 于 ref）后再行归一 + KNN，去通道尺度/偏移混淆 | 单一配置 |
| AGR2 | 匹配侧·跨图一致性 | 逐 patch 取每个支持图内最近单元距离，取 **两个最近支持图之和/2**（要求跨图一致，抑制单图纹理重复误报） | 单一配置 |
| K5 | 匹配侧·KNN 深度 | 每 patch 距离 = 合并 bank **top-5 平均**（抗最近邻翻转） | 单一配置 |
| WZ | 距离空间·图内自归一 | 对每张 test 图内 1024 patch 距离做稳健中心化/尺度化（median/MAD），去图级光度偏移；免标签 | 单一配置 |
| CSR | 描述子几何·中心-邻域残差 | r = z − 3×3 邻域均值 z̄（查询/参考同规则、行 L2），r 的 KNN 距离 g 与 z 距离相加：s = d_z + α·d_g | α ∈ {0.25, 0.5}（lead 取宏大者） |
| MAP | 分支分数级融合 | dino-only 与 clip-only 单分支 map 在像素级 min/max/mean 融合（距离=异常度，min=AND/均=mean 口径） | min / max / mean 三变体（族内各自对照其分支，门仍 vs C0） |

机制族覆盖：特征标定（CS）、参考结构/一致性（AGR2）、匹配深度（K5）、距离空间自校准（WZ）、局部描述子几何（CSR）、分数级集成（MAP）——与已归档的（特征 concat、关系 concat、coreset、可学习重标定、分辨率）不重叠。

## 诚实边界
- 全部是"同图/参考集内"无监督变换；不引入新的监督信号或训练。
- 若全负：构成一份**广度闭合证据**（这些族亦无法超 A1），A1 仍为唯一冻结方法；只有获得授权（新数据/结构先验/训练）才继续。
- 若某族正：不自动并入，需按纪律进入复现验证 + 简单控制（如 AGR2/K5 对等成本 k=1/k=2 的对照）后单独汇报。
