## 2. 若 S0 波次失败或时间富余 → 备选创新方向（按“成本×信息价值”排序）

### P5-A：S1-HGLC 全局—局部一致性校准诊断（16 §3；中等 GPU，~1h）
- 现状缺口：现有 cache 只有 patch_features，无 DINO CLS / CLIP global / 文本 global。
- 诊断第一步 = 在 MPDD s0×k{1,2,4} 导出冻结 CLS/global（vitb14@448 CLS、CLIP-L/14@336
  global、AnomalyCLIP text global logit），CPU 算 Image-AUROC/AP，对照 A1 max/top1%。
- 通过门（16 §3.3）：单全局分数相对 A1 image score 平均 Image-AP ≥ +0.010 才立项。
- 论文叙事价值：给“双几何像素融合”加上一个**图像级模态一致性校验**，缓解“只并两个
  视觉像素分支”的观感；但仍是同一视觉主干的不同聚合级别，属辅助模块。

### P5-B：S2-GPMR 概率原型流形残差的 CPU 预检（16 §4；成本最低，纯 CPU）
- 关键判断：S2 的“信息价值”预检其实可以**只用现有 frozen cache**（DINO/CLIP 的
  ref/test patch features 已在盘上）做：正常 patch 分桶→GMM/原型后验→
  responsibility entropy；检查熵是否与真实逐像素错误相关（Spearman |ρ|）。
- 若 |ρ|<0.3（16 §4.3 停止线）即归档；否则才考虑 GPU 全量（风险高，工程量大）。

### P5-C：把 S0 的“正常-only 可靠性保护”提升为通用框架（低成本改写叙事 + 1 个探针）
- 观感问题本质：S0 只有两个视觉专家（A1、SUB），且二者都是 DINO 系表征（A1=DINO+CLIP
  分支 concat，SUB=DINOv2-giant 子空间）。评审会问“为何不直接更大模型/更多主干”。
- 思路：把 S0 的贡献表述为 **“以 A1 为锚、正常-only 稳定性可靠性保护的证据融合框架”**，
  再实例化第二个**异构**证据源来证明框架通用性。候选异构源（成本递增）：
  1. AnomalyCLIP **文本分支**：已有 text 特征 cache，可产生 image-level 文本证据
     （像素图 0.139 不可直接用，但 image 级校准可用）；文档已记录。
  2. **频率/结构先验**（16 §5 明确暂不推荐，除非有新证据）→ 不做。
  3. **同一个 A1 体系内不同分辨率/不同聚合（如单层 vs 深层 concat）**：证明
     “专家”不一定需要换主干，几何不同即可——这反过来也帮 S0 的内部一致性叙述。
- 探针（1 GPU smoke，~10-20 min）：对 connector（A1 强、SUB 弱）与 tubes（SUB 强）
  检查 A1-单层 vs A1-concat 是否呈现与 (A1,SUB) 互补性结构不同的错误同构性。
  若“同主干不同聚合层”也能给出可识别的互补性，则可把 S0 从“两个视觉分支”
  升级为“正常性几何异构证据 + 稳定性门控”的一般方法学 claim。

### P5-D（若 Wave1 通过才更有依据）：A1+SUB+文本 的“第三证据”最小验证
