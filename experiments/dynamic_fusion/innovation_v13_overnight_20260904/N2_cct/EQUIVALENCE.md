# N2 / CCT：关键等价性分析（doc27 §6「等价性检查」）

## 1. 设置与记号

锚点 = support 正常单元（k1 探针用 16×16，anchor 容量 = 每单元公平份额 1/256）。
对 query 单元 i 与 anchor j：
- C_D[i,j] = 1 − ⟨d_i, d_j⟩（dino L11，行归一）
- C_C[i,j] = 1 − ⟨c_i, c_j⟩（clip L24 对齐 32→16 池化，行归一）
- 融合：f_i = concat 后整体 L2 归一（0.5/0.5，A1 协议）。因分支向量单位范数，
  ‖0.5[d_i;c_i]‖² = 0.5 → 归一后 ⟨f_i,f_j⟩ = (⟨d_i,d_j⟩+⟨c_i,c_j⟩)/2，故
  **C_fused = (C_D + C_C) / 2（逐项精确成立）**。

## 2. 什么条件下会退化为 concat-OT

目标（实现版，无 refuse）：
  min  ⟨P_D,C_D⟩ + ⟨P_C,C_C⟩ + ε[H(P_D)+H(P_C)] + γ Σ_i JS(P_D[i,:], P_C[i,:])
  s.t. P_D, P_C 行/列边缘各为均匀（容量 = 每 anchor 公平份额，行列总量守恒）。

- (a) 单计划实现：若把 P_D=P_C=P 强加并用 C=(C_D+C_C)/2，即为 concat 特征上的平衡 OT
  —— 本实现**不是**这种（保留两个私有计划 P_D≠P_C）。
- (b) γ→∞ 极限：JS=0 ⟺ P_D=P_C（逐行一致），目标退化为 2⟨P,C_avg⟩+ε·2H(P)，
  与 concat-OT 同解（熵正则只差常数倍）。故**只有耦合项极强时**才退化。
- (c) C_D≈C_C（两分支在 normal anchors 上近似共线/单调一致）时，最优解自然 P_D≈P_C，
  即使 γ=0 也与 concat-OT 几乎同解 → 此时两分支计划不携带额外信息（REDUNDANT 情形）。

## 3. 非退化成立的条件（机制相关）

两分支**不一致**时双计划才有独立价值：同一 query 单元在 dino 距离小（纹理近）而 clip
距离大（语义/上下文不匹配），或反之；复制造成容量挤占在某一分支先触顶而另一分支未触顶。
此时 γ 有限耦合在"两分支强烈分歧"的单元上承担成本，输出不同于 concat-OT。

## 4. 经验核查（本目录 R0.json / EMPIRICAL.json）

- R0 中 cct_c 与 concat_ot 的逐单元 copy-gap 差异、以及 cct_i 与 concat_ot 的差异，
  量化两分支计划相对 concat-OT 的增量。
- 记录 P_D 与 P_C 行分配的 KL/相关性（若≈1 → REDUNDANT 声明）。

## 5. 结论（R0 六类后填写，2026-09-04）

- copy-gap：cct_i 0.0444、cct_c 0.0459、concat_ot 0.0244 → 双计划容量匹配比 concat-OT
  高约 +0.020（≥0.003），**经验上未退化**为 concat-OT（§2(b) γ 非无穷）。
- cct_c − cct_i ≈ +0.0015：JS 行耦合增量近零 → γ=0.5 下耦合不贡献；此探针不构成
  "双分支协同"证据（单分支 DINO 容量 0.0788 反而最高）。
- 数学关系：C_fused ≡ (C_D+C_C)/2 精确成立（§1）；退化只在 γ→∞ 或 C_D≈C_C 时发生；
  实测 C_D、C_C 分歧足以让双计划 ≠ concat-OT，但增益来自容量本身而非分支交互。
