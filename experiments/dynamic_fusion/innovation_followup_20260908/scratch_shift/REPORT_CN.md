# 划痕亮暗极性与低对比度压力测试

状态：已完成。冻结DINO、两类k2、每图预定seed0划痕，4个基础mask；每mask四种渲染，两分辨率共32个方法行。严格使用另一张normal support建memory，不读真实test、不调参。

原mask与缓存逐字节一致，旧配方重新编码的feature误差记录在RESULTS.json的parity。所有arm用单位特征Euclidean NN与同一dists2map到1024后处理；不同脚本绝对AP不可拼接。

**候选信号：**在这4个固定位置上，高分辨率的细划痕收益不只出现于旧的暗化配方，在反极性和低对比度下也保留。低对比度暗划痕收益较小。该探针检验的是机制边界，没有改进检测器，不能称新算法。

**限制：**仅4个基础mask，亮暗变体共享位置和图像，32行不是32个独立样本；位置、宽度、方向覆盖有限。仍不能替代昨日已出现总体pixelAP退化的真实诊断。

后续值得研究：在同算力下保留高分辨率输入，而不是盲目增加backbone或堆分数融合。小backbone×高分辨率的有界探针已经单独派发，结论待实测。
